# Open questions

Things this project knows it does not know, or has deliberately left for later. Each should
become a GitHub issue once the repository has a GitHub home. Until then this list is the tracker.

| Question | Why it is open | What would settle it |
| --- | --- | --- |
| What does a processor do when two clients register the same IP-ID? | The system this was developed on left conflicting notes: one observation that claiming a slot displaced nothing, and a later plan that assumed a deliberate collision would make the processor end the existing session. Neither was tested on purpose. See [ip-id-conflicts.md](../troubleshooting/ip-id-conflicts.md). | A controlled test on a slot no real panel uses, on more than one processor generation, with both clients logging. |
| Do analog and serial writes work? | The encodings come from [klenae/python-cipclient](https://github.com/klenae/python-cipclient). The development system's program accepted no analog write from a panel, so the bytes have never been seen to work. See [cip-wire-format.md](../protocol/cip-wire-format.md). | One report from a system whose program accepts analog or serial input from a panel. |
| Authenticated and encrypted CIP | 3-series and 4-series processors can require a username and password, and CIP over TLS on port 41796. Nothing here has been tested against either. See [unsupported-systems.md](../troubleshooting/unsupported-systems.md). | Access to such a processor, and a capture of a real panel's handshake with it. |
| Console login in the CLI | `cip-panel ipids` and `cip-panel console` answer a login prompt, but have only been run against consoles that ask for no password. | One run against an authenticated console. |
| Cursor-zone audio | A working pattern exists for audio zones selected through a per-slot cursor, but it was built and validated against one program only. See [cursor-zone-audio.md](../patterns/cursor-zone-audio.md) and [ADR 0009](../adr/0009-cursor-zone-audio-deferred.md). | A second program using the same pattern, so the generic version can be checked against two. |
| Panel project formats other than TSW x52 | Only an x52 `Environment.xml` has been available to parse. x60 and x70 panels use HTML5 projects. See [panel-project-files.md](../inventory/panel-project-files.md). | A sample project from a newer panel family. |
| Has this run in a live Home Assistant? | The integration is tested in the Home Assistant test harness against a fake processor. Against one real processor (an AADS), `cip-panel ipids` parsed the real IP table, `cip-panel listen` registered and recorded the menu dump, and the integration's hub ran listen-only, refused the entry press, and sent no data frame beyond the update request. The integration has not been installed on a live Home Assistant instance. | Installing it on a live instance, listen-only first. |
| What does ONLINE mean for a gateway IP-ID? | On one processor, touch panel slots listed as `Gway` at 127.0.0.1 read ONLINE with their panel unplugged, and one slot's status changed between two reads minutes apart with nothing touched. | Watching the status across a panel being unplugged and plugged back in, with timestamps. |
